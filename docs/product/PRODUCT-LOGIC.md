# PRODUCT LOGIC

## Positioning
- Product: platform for avitologists on top of Avito API.
- Audience: avitologists (agencies and freelancers).
- Value: more leads with same ad budget and less manual routine around listing optimization.

## User Journey
1. Registration: email/password or Telegram login.
2. Onboarding:
  - niche selection
  - goal selection
  - connect Avito account or check a listing by link
3. Dashboard: all listings, underperforming listings, audits, stats, action queue.

## Data Hub
- Connect Avito account.
- Import listings into unified workspace.
- Sync key listing data and metrics.
- Provide fast access to each listing for audit and improvement.

## Audit
- Fast audit by listing link.
- Text score.
- Photo score.
- Infographic score.
- Prioritized recommendations.

## Listing Creation
- Improved version draft based on audit.
- Structured edits for title, offer, proof blocks, CTA.
- Visual recommendations for first photo and infographic.
- Manual edit and controlled update workflow.

## A/B Testing
- Test target: title, description, or price.
- Additional target: first photo or infographic.
- Variation set: A/B/C.
- Rotation modes:
  - simultaneous
  - sequential (recommended)

## Metrics and Insights
- Views, contacts, CTR, conversion.
- Collection cycle: each 10-15 minutes.
- Outcome: explicit weak listings, explicit winner and conversion uplift.

## Market Benchmark
- Compare listing against market benchmark by city, category, service, and price segment.
- Show where the listing is below market in title, photo, infographic, price, and offer.
- Use benchmark as a recommendation amplifier, not as a raw competitors list.

## Client Reporting
- Short report on what was weak.
- What was changed.
- What improved after changes.
- What gap existed against the market before and after changes.

## Monetization
- Free: one project/listing, manual export only.
- Basic: audits, recommendations, improved versions.
- Pro: analytics, history, A/B testing, up to 50 listings.
- Agency: no limits, advanced API workflows, multi-account, client reporting.

## Paywall Triggers
- More listings and analytics depth require higher plan.
- A/B test requires higher plan.
- Advanced API workflows require higher plan.

## Core Loop
Connect account -> import listings -> detect weak listing -> audit -> improve -> compare result -> repeat.
