# MVP BACKLOG

## Priority 0
- Auth flow: register/login/refresh/logout.
- User workspace and project entity.
- Avito account connection and token lifecycle.
- Listing import and local normalization layer.

## Priority 1
- Unified listings dashboard from Avito API.
- Detection of underperforming listings.
- Fast audit by listing link.
- Rule-based text audit engine.
- Rule-based photo and infographic audit.
- Recommendation engine with prioritized fixes.

## Priority 2
- Improvement workspace for updated listing version.
- Listing update flow back into working process.
- Change history and before/after comparison.
- Client-ready short report.

## Priority 3
- Metrics model and ingestion from Avito-connected data.
- Analytics UI: views, contacts, CTR, conversion.
- Audit score trends over time.
- Variation management and hypothesis tracking.
- Market benchmark v1 by city, service, and price segment.
- Internal niche benchmarks and pattern library.
- Audit UI: market gap block inside listing audit.

## Priority 4
- A/B test creation.
- Start mode: simultaneous or sequential.
- Basic winner logic and result reporting.
- Similar listings comparison and market gap reporting.

## Priority 5
- Plans and paywall checks.
- Billing integration and feature gates.
- Competitor monitoring and deeper benchmark automation.

## Definition of Done
- Has tests for core use cases.
- Has docs update in README/CHANGELOG.
- Has migration-safe deployment path.
- Recommendations are explainable and tied to concrete checks.
