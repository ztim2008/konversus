# Тайный покупатель сайтов — План проекта

Внутренний инструмент для поиска клиентов. Ты не ждёшь когда клиент сам найдёт тебя — ты находишь сайты с проблемами и присылаешь владельцу готовый отчёт с предложением исправить.

## Как это работает

### Шаг 1: Поиск сайтов

Ты вводишь город и нишу. Система ищет сайты через:

| Источник | Что ищет | API |
|----------|----------|-----|
| Яндекс Карты | Компании по категории | scraping / API |
| 2ГИС | Компании с сайтами | scraping |
| Яндекс Поиск | `стоматология москва сайт` | scraping |
| Google Maps | Businesses with websites | scraping |

На выходе: список доменов + названия компаний + контакты (если есть).

### Шаг 2: Аудит

Каждый домен прогоняется через:

| Модуль | Что проверяет | Время |
|--------|--------------|-------|
| SSL Doctor | SSL, HTTPS, DNS | 2 сек/сайт |
| Архитектор | SEO, дизайн, скорость | 5 сек/сайт |
| Mobile Check | Мобильная адаптация | 2 сек/сайт |

Итого: ~10 секунд на сайт. 20 сайтов = 3 минуты.

### Шаг 3: Оценка

Каждый сайт получает сводный балл:

```
Общий счёт: 0-100

SSL:     0-35 баллов
SEO:     0-25 баллов
Mobile:  0-20 баллов
Speed:   0-20 баллов

< 40 — КРИТИЧЕСКИ (срочно написать)
40-60 — ПЛОХО (написать)
60-80 — СРЕДНЕ (в список)
> 80 — ХОРОШО (пропустить)
```

### Шаг 4: Контакты

Для каждого сайта — найти контакты:
- Телефон (whois / карты / сайт)
- Email (whois / сайт)
- Форма обратной связи
- Соцсети

## Интеграция с существующими модулями

```
/secret-shopper
  ├──→ SSL Doctor (ssl.konversus.ru/api/check)      — проверка SSL
  ├──→ Архитектор (/architect API)                   — AI-анализ
  └──→ Внутренний checker (src/lib/ssl/checker.ts)  — HTTP/DNS
```

## Фазы разработки

### Фаза 1: Ядро (1 день)
- Форма поиска (город + ниша)
- Поиск сайтов через Яндекс Поиск (scraping)
- Базовый аудит (SSL + HTTP) через SSL Doctor API
- Таблица результатов

### Фаза 2: Глубокий аудит (1 день)
- Интеграция с Архитектором (SEO, дизайн, скорость)
- Mobile check
- Сводный балл и сортировка

### Фаза 3: Контакты и отчёты (1 день)
- Поиск контактов (whois, сайт)
- Генерация PDF-отчёта
- Шаблоны сообщений

### Фаза 4: Автоматизация (2 дня)
- Запланированные поиски (крон)
- Уведомления о новых сайтах в нише
- История поисков
- Сравнение «до и после»

## Как это встраивается в экосистему

```
konversus.ru/secret-shopper (личный инструмент)
        │
        ├──→ SSL Doctor (техническая проверка)

        └──→ Leads AI (поиск контактов)

Результат → PDF-отчёт → Telegram → клиент → Factory Proposal Builder
```

- **Переменные** — [ИМЯ], [ДОМЕН], [ПРОБЛЕМА_1] и т.д. подставляются автоматически
- **Предпросмотр** — как будет выглядеть письмо в Telegram/Email
- **Править вручную** — можно дописать, удалить, изменить тон
- **Сохранить шаблон** — для этой ниши
- **История** — кому отправлял, когда, что ответили

## Шаблоны под нишу

Разные ниши = разный тон.

### Стоматологии / Клиники
Акцент на доверие и репутацию. «Клиенты ищут вас в интернете, а сайт не вызывает доверия.»

### Строительство / Ремонт
Акцент на портфолио и конкретику. «Ваши конкуренты уже принимают заявки с сайта. Вы теряете клиентов.»

### Рестораны / Кафе
Акцент на мобильную версию. «90% клиентов смотрят меню с телефона. Ваше не открывается.»

### Автосервисы
Акцент на запись онлайн. «Клиенты хотят записаться через сайт, а не звонить.»
