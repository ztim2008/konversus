# Идеология Konversus

## Главный принцип

**Konversus — не набор разрозненных сервисов. Это экосистема конверсионных модулей для сайта.**

Каждый модуль решает конкретную задачу владельца бизнеса. Модули не конкурируют — они дополняют друг друга, обмениваются трафиком и усиливают ценность экосистемы.

## Философия

> Владелец бизнеса не хочет знать про SSL, ACME, PEM, DNS.  
> Он хочет знать: «Мой сайт работает?», «Клиенты могут зайти?», «Где брать заказы?»

Каждый модуль отвечает на один человеческий вопрос, а не на технический.

## Экосистема

```
konversus.ru (ХАБ)
├── Архитектор     «Что мешает бизнесу расти?»
├── SSL Doctor     «С моим сайтом всё в порядке?»
├── Leads AI       «Где брать заказы?»
└── ...            «???» (следующий модуль)
```

## Как модули связаны

| Модуль | Отдаёт трафик в | Получает трафик из |
|--------|----------------|-------------------|
| **Архитектор** | SSL Doctor, Leads AI | Главная |
| **SSL Doctor** | Архитектор, Leads AI | Главная, Архитектор |
| **Leads AI** | Архитектор, SSL Doctor | Главная, Архитектор |

Каждый модуль:
- Имеет **собственный домен** (ssl.konversus.ru, leads.konversus.ru)
- Имеет **собственный бренд** (SSL Doctor, Leads AI)
- Имеет **собственную монетизацию**
- Содержит **кросс-ссылки** на другие модули
- Использует **общую дизайн-систему** (Inter, Lucide, тёмная тема, токены)

## Архитектурные принципы

1. **Общий стек** — Next.js 16, TypeScript, PostgreSQL, Prisma, Redis, Docker, PM2
2. **Общая авторизация** — NextAuth v4, Яндекс ID, email/password
3. **Изоляция данных** — отдельная БД на каждый модуль, multi-tenant внутри модуля
4. **Дизайн-токены** — единая система CSS-переменных, Inter, Lucide
5. **Кросс-ссылки** — каждый модуль ссылается на другие в футере/секциях

## Монетизация

Каждый модуль имеет свою тарифную сетку. Плюс — **перекрёстные продажи** через экосистему:

- SSL Doctor нашёл проблему → «Нужна помощь?» → Telegram @bilarius → платная консультация
- Архитектор показал слабые места сайта → «Нужен аудит?» → Factory Proposal Builder
- Leads AI привлёк заявки → «Нужен сайт?» → Factory Proposal Builder

## Правила создания нового модуля

1. Отвечает на **один человеческий вопрос**
2. Использует **общий стек и дизайн**
3. Имеет **собственный домен**
4. Содержит **кросс-ссылки** на существующие модули
5. **Не дублирует** функциональность других модулей
6. **Сплитует трафик** — отправляет пользователя дальше по экосистеме
7. **Замыкает цикл** — из проблемы → в решение → в контакт
