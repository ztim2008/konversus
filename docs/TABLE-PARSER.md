# Парсер таблиц — сервис

## Концепция

Встроенный инструмент для извлечения таблиц из любого источника. Пользователь копирует таблицу (Excel, Google Таблицы, сайт, CSV, Markdown) и вставляет в текстовое поле — сервис автоматически определяет формат, парсит данные и позволяет экспортировать в HTML, CSV или JSON.

## Как это работает

### Шаг 1: Вставка данных

Пользователь вставляет данные в текстовое поле. Сервис автоматически определяет формат:

| Формат | Признак | Пример источника |
|--------|---------|------------------|
| HTML | Начинается с `<`, содержит закрывающие теги | Любая веб-страница |
| TSV (Excel) | Содержит символ табуляции `\t` | Excel, Google Таблицы, Numbers |
| CSV | Запятые как разделители, стабильное число колонок | Экспорт из CRM, 1С, банков |
| Markdown | Строки с `|` и строка-разделитель `|---|---|` | GitHub, Obsidian, Notion |
| Текст | Падение — группировка по 2+ пробелам | Терминал, логи, консоль |

### Шаг 2: Парсинг

В зависимости от определённого формата вызывается соответствующий парсер:

| Функция | Формат | Особенности |
|---------|--------|-------------|
| `parseHTML()` | HTML | Учитывает `colspan` и `rowspan` |
| `parseDelimited(text, sep)` | TSV / CSV | Обрезает кавычки, пустые строки |
| `parseMarkdown()` | Markdown | Пропускает строку-разделитель |
| `parseSpaces()` | Текст | Разбивает по 2+ пробелам |

### Шаг 3: Экспорт

После разбора доступны три формата экспорта:

- **HTML** — адаптивная таблица с `overflow-x:auto` для вставки на сайт (Tilda, WordPress)
- **CSV** — для Excel, Google Таблиц, 1С
- **JSON** — массив объектов для разработчиков

## Форматы экспорта

### HTML

```html
<div style="overflow-x:auto;max-width:100%;">
<table style="border-collapse:collapse;width:100%;font-size:14px;">
  <thead>
    <tr>
      <th style="border:1px solid #d1d5db;padding:10px 12px;...">Название</th>
      <th style="border:1px solid #d1d5db;padding:10px 12px;...">Цена</th>
    </tr>
```

## Детектор форматов (`detectFormat`)

Последовательность проверки:

1. **HTML** — текст начинается с `<` и содержит закрывающие теги (`</слово>`)
2. **TSV** — в тексте есть символ табуляции `\t`
3. **Markdown** — есть строки с `|` и хотя бы одна строка-разделитель вида `|---|---|`
4. **CSV** — строки разделены запятыми, стабильное число колонок (совпадение ≥70%)
5. **По умолчанию** — парсинг по пробелам (разделитель 2+ пробела)

## Обработка colspan/rowspan

При парсинге HTML учитываются атрибуты `colspan` и `rowspan`:

```
colspan="2" → ячейка занимает 2 колонки (сдвиг следующих ячеек)
rowspan="3" → ячейка занимает 3 строки (резервирование колонки)

Алгоритм: массив t[] отслеживает занятые колонки.
При встрече rowspan=N: t[col] = N-1.
На каждой строке: t[col] декрементируется.
Пока t[col] > 0: ячейка пропускается.
```

## Интеграция с Tilda

Для вставки таблицы на Tilda:

1. Разобрать таблицу → нажать **HTML** → код скопирован
2. В Tilda: добавить блок **Другой код** (категория «Другое»)
3. Вставить код → сохранить → опубликовать

Таблица адаптивная: на мобильных устройствах появляется горизонтальный скролл.

## Использование

```
konversus.ru/tables

Простое использование:
  1. Ctrl+V таблицы → нажать «Разобрать»
  2. Выбрать формат экспорта (HTML/CSV/JSON)
  3. Вставить куда нужно

Загрузка по URL:
  1. Нажать «Загрузить по ссылке»
  2. Вставить URL страницы с таблицей
  3. Нажать «Загрузить»
  4. Экспортировать в нужном формате
```
