## 1. Срез продукта (как есть)

### Формула дня

```
УТРО = ПЛАН (TG + «Сегодня»)
ДЕНЬ = РУЧНАЯ ОТПРАВКА / ПРОПУСК / ручной URL
ВЕЧЕР = ФАКТ (TG daily-report + «Статистика»)
```

Бренд исходящих писем: **lead-web.pro**.

### Карта экранов админки (`/dashboard/secret-shopper`)

| Вкладка | Роль | Зрелость |
|---------|------|----------|
| **Сегодня** | Главный рабочий стол дня | 🟩 рабочий |
| **Статистика** | Факт дня + история | 🟩 ок |
| **Рулетка** | Лимит, веса, прогноз 14 утр | 🟩 только что |
| **Радары** | Старый контур Maps/поиск | 🟨 путает с Auto |
| **Лиды в работе** | Статусы / ответы / follow-up | 🟨 сырой |

### Два контура в одном UI (главная системная боль)

```
Auto (утро):    Рулетка → SERP → queued → Сегодня → TG
Legacy (Радары): город×ниша Maps → таблица → KpModal → другой send
```

Оператор видит «Радары» и думает, что ими крутится утро. На деле Auto их **не использует**. Это уже зафиксировано в плане ниш.

### TG (канал напарника)

| Момент | Что видит |
|--------|-----------|
| Утро | Пачка · город · вертикаль · ниша · топ-5 скринов+КП |
| Ручной URL | ➕ + карточка |
| Отправка | ✅ + скрин + текст письма |
| Пропуск | ⏭ коротко + слот свободен |
| Ответ | 🔥 |
| Вечер | 📊 факт (если sent>0) |

## 3. Целевой UX (один экран в голове)

```
[ Лид-радар · lead-web.pro ]
  День:   Сегодня* | Статистика
  Настройки: Рулетка | (Радары — «архив поиска»)
  CRM:    Лиды в работе

Сегодня =
  шапка дня (город · вертикаль · ниша · N/лимит · осталось)
  [▾ Добавить URL]  ← свёрнуто по умолчанию
  лента карточек: скрин | суть | Отправить | Пропуск
  toast при действиях
```

Принципы:

1. **Один главный путь дня** — вкладка Сегодня.  
2. Legacy не удаляем сразу — **прячем/подписываем**.  
3. **Обратная связь** на каждое действие (toast + счётчик).  
4. Везде **lead-web.pro** для клиента.  
5. TG = зеркало админки, админка = полный контроль.
