## 2026-09-11 — Фикс TG скринов 404

### Симптом

Утренний дайджест: текст КП ушёл (`kpSent: 5`), фото нет (`photosSent: 0`). URL вида `https://konversus.ru/uploads/lead-screenshots/*.jpg` → 404.

### Причина

1. Файлы пишутся в `public/uploads/...`, а nginx `root` = корень проекта → ищет `/uploads/...` мимо `public/`.  
2. Next.js кэширует список `public/` при старте → jpeg после рестарта (ночной cron 06:00) не отдаёт, пока снова не `pm2 restart`.

### Фикс

- Symlink `uploads → public/uploads` (+ автосоздание в `captureSiteScreenshot`).  
- Telegram `sendPhoto`: сначала multipart с диска (`screenshot_path`), URL — запасной.  
- Досылка 5 скринов за 2026-09-11 в группу — ok.  
- `harness:check` OK; `konversus-fpb` перезапущен.
