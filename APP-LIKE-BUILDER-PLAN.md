# План развития: App-Like Web Builder (Конструктор Web-приложений)

## 1. Концепция: Смена парадигмы
В отличие от классических конструкторов (Tilda, Wix), которые адаптируют десктоп под мобильные, мы создаем **Mobile-First** платформу. Сайт должен ощущаться как дорогое нативное приложение, работающее в браузере.

### Ключевые принципы:
*   **Единый дизайн:** Никакой сложной адаптации. Один дизайн для всех устройств.
*   **Desktop-версия:** Не растягиваем контент. На больших экранах сайт отображается в центрированном контейнере (имитация планшета/телефона) с размытым фоном или стильной подложкой.
*   **UX Приложения:** Отказ от классических меню в пользу Bottom Navigation Bar (нижняя панель) и жестов.

## 2. Техническая реализация "Легкости"
*   **SPA (Single Page Application):** Мгновенные переходы без перезагрузки страницы (используем технологии типа swup.js/barba.js).
*   **PWA (Progressive Web App):** Автоматическая генерация `manifest.json`, чтобы сайт можно было установить на экран телефона как иконку.
*   **Производительность:** Lazy Loading всего контента, авто-конвертация изображений в WebP.

## 3. Уникальные модули (App Widgets)
Вместо стандартных веб-блоков используем паттерны мобильных приложений:
1.  **Stories (Истории):** Горизонтальная лента кружочков сверху. При клике — полноэкранный просмотр фото/видео.
2.  **Swipe Cards:** Карточки товаров или статей, которые можно листать свайпом влево-вправо.
3.  **Bottom Navigation:** Фиксированное меню снизу (Главная, Поиск, Корзина, Профиль).
4.  **Floating Action Button (FAB):** Плавающая кнопка целевого действия.

## 4. AI и SEO (Growth Hacking)
*   **AI Генератор контента:**
    *   Интеграция с LLM (OpenAI/DeepSeek).
    *   Генерация структуры статьи и текста по одной теме.
    *   Автоматический подбор картинок (Unsplash API).
*   **SEO-Автопилот:**
    *   Авто-генерация Meta Title/Description.
    *   Микроразметка Schema.org (Article, Product) для богатых сниппетов в Google.
    *   Mobile-First индексация как преимущество.

## 5. Новые требования (Update 19.12.2025)

### 5.1. Управление только Глобальными Стилями
*   **Запрет на микро-менеджмент:** Убираем настройки отступов (padding/margin) и размеров шрифтов для каждого блока.
*   **Design System:** Пользователь выбирает только "Тему" (Цветовую палитру, Шрифтовую пару, Радиус скругления). Все отступы вычисляются автоматически по гармонической сетке. Это гарантирует, что сайт невозможно "сломать" кривыми руками.

### 5.2. E-commerce и Парсинг
*   **Ozon/Marketplace Parser:** Вставляешь ссылку на товар (Ozon, WB) -> Конструктор сам парсит фото, цену, описание и создает карточку товара.
*   **Встроенный каталог:** Управление товарами прямо внутри конструктора.

### 5.3. Mobile Admin (Управление с телефона)
*   **Редактор в кармане:** Интерфейс самого конструктора должен быть на 100% удобен на телефоне.
    *   Вместо Drag-and-Drop (неудобно на таче) -> Интерфейс "Tap to Add" и "Bottom Sheet" (шторки снизу) для настроек.
*   **Медиа-блогинг:** Загрузка фото/видео прямо с камеры телефона. Автосохранение черновиков (как в Telegram).

## 7. Мысли и заметки
*   **Проблема 1200px:** На планшетах и небольших ноутбуках можно использовать Grid-сетку (2-3 колонки), чтобы эффективно использовать пространство, не ломая "мобильную" логику.
*   **Название:** App-Web Builder / Mobile Story Builder.
*   **Монетизация:** Идеально подходит для блогеров, инфлюенсеров, малого бизнеса (меню ресторанов, портфолио), которым нужен сайт "как инстаграм".
