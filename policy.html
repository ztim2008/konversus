1. Какие данные мы можем обрабатывать

В рамках работы сервиса могут обрабатываться только те данные, которые нужны для авторизации, работы кабинета и улучшения объявлений.

  • данные профиля пользователя после входа через Яндекс ID;
  • технические данные, нужные для работы сайта и кабинета;
  • данные объявлений, если пользователь сам работает с ними внутри сервиса;
  • данные, которые пользователь добровольно вводит в формы сервиса.

2. Зачем нужны эти данные

  • чтобы авторизовать пользователя и дать доступ в личный кабинет;
  • чтобы показывать объявления, шаблоны, результаты аудита и рекомендации;
  • чтобы развивать сервис и улучшать пользовательские сценарии;
  • чтобы отвечать на обращения пользователя по email.

3. Что мы не делаем

  • не публикуем персональные данные пользователя в открытом доступе;
  • не продаем персональные данные третьим лицам;
  • не запрашиваем лишние данные, которые не нужны для работы сервиса.

4. Как хранятся и защищаются данные

Мы используем серверные настройки, ограничения доступа и внутренние технические меры, чтобы снизить риск утечки или несанкционированного доступа к данным.

Секреты интеграций и служебные токены не размещаются в открытом коде страницы и не предназначены для публичного доступа.

5. Интеграции и сторонние сервисы

Сервис уже использует авторизацию через Яндекс ID. Интеграция с Avito API находится в стадии подключения и будет использоваться только для тех функций, которые пользователь явно запускает внутри сервиса.

Часть возможностей проекта находится в разработке. По мере подключения новых функций политика может дополняться и уточняться.
