# Концепция Дизайн-системы: "Nordic Editorial"

## 1. Философия стиля
Мы объединяем **Скандинавский минимализм** и **Журнальную верстку**.
*   **Скандинавский стиль:** Функциональность, много "воздуха" (белого пространства), натуральные цвета, чистые линии, отсутствие визуального шума.
*   **Журнальный стиль (Editorial):** Акцент на типографику (контраст шрифтов), асимметричные сетки, качественные изображения, врезки с цитатами, буквицы.

## 2. Визуальный язык (Design Tokens)

### Типографика
Используем контрастную пару:
*   **Заголовки (Display):** Элегантный шрифт с засечками (Serif).
    *   *Примеры:* Playfair Display, Merriweather, Cormorant Garamond.
    *   *Характер:* Крупные кегли, плотный трекинг, возможно использование курсива для акцентов.
*   **Основной текст (Body):** Чистый гротеск (Sans-Serif).
    *   *Примеры:* Inter, Lato, Manrope.
    *   *Характер:* Высокая читаемость, увеличенный интерлиньяж (line-height 1.6-1.8).

### Цветовая палитра
Отказ от "кричащих" цветов в пользу сложных, приглушенных оттенков.
*   **База:** Off-white (слоновая кость), Light Grey, Deep Charcoal (вместо чистого черного).
*   **Акценты (Nature inspired):**
    *   *Sage Green* (Шалфей)
    *   *Dusty Blue* (Пыльный синий)
    *   *Terracotta* (Терракота)
    *   *Muted Gold* (Приглушенное золото)

### Сетка и Композиция
*   **12-колоночная сетка:** Но контент редко занимает все 12 колонок.
*   **Центральная ось:** Текстовые блоки часто узкие (600-700px) для удобства чтения.
*   **Асимметрия:** Изображения могут выходить за пределы контейнера, накладываться друг на друга (эффект коллажа).

## 3. Библиотека компонентов (Blocks)

Система будет строиться из готовых блоков, которые стыкуются друг с другом.

### A. Hero Sections (Первый экран)
1.  **"Cover Story":** Заголовок по центру, огромное фоновое фото с затемнением.
2.  **"Split Screen":** 50% фото / 50% текст (минимализм).
3.  **"Typography Lead":** Огромный заголовок на чистом фоне, фото маленькое сбоку.

### B. Content Blocks (Контент)
1.  **"Editorial Article":** Текст с буквицей (Drop cap), врезки с цитатами по центру или сбоку.
2.  **"Masonry Gallery":** Галерея "кирпичной кладкой" (разные пропорции фото).
3.  **"Feature List":** Список преимуществ с тонкими иконками или цифрами (01, 02, 03) крупным шрифтом.

### C. Navigation & Footer
1.  **"Sticky Minimal":** Логотип и "Гамбургер" (даже на десктопе) для чистоты, либо аккуратная строка меню.
2.  **"Fat Footer":** Многоколоночный подвал с картой сайта, подпиской на рассылку и соцсетями.

## 4. Техническая реализация (Architecture)

### Стек
*   **Core:** PHP (генерация страниц) + JSON (хранение структуры).
*   **Styling:** Tailwind CSS (идеален для дизайн-систем благодаря конфигу).
*   **Interactivity:** Alpine.js (легковесный JS для меню, слайдеров).

### Структура данных (JSON)
Вместо правки HTML, мы будем хранить **состояние** страницы.
```json
{
  "settings": {
    "theme": "nordic-light",
    "fontPair": "playfair-inter"
  },
  "blocks": [
    {
      "type": "hero-split",
      "content": {
        "title": "Новая коллекция",
        "image": "/uploads/hero.jpg"
      }
    },
    {
      "type": "text-editorial",
      "content": { "body": "..." }
    }
  ]
}
```

## 5. План разработки (Roadmap)

1.  **Setup:** Настройка Tailwind config с нашей палитрой и шрифтами.
2.  **Base Layout:** Создание "оболочки" (Header, Footer, Grid wrapper).
3.  **Atoms & Molecules:** Кнопки, инпуты, типографика (H1-H6, p, quote).
4.  **Organisms (Blocks):** Верстка основных блоков (Hero, Gallery, Text).
5.  **Builder:** Создание интерфейса для добавления/перемещения блоков (Drag & Drop).
